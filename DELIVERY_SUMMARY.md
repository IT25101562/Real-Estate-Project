## 🚀 Quick Start (Choose One)

### Option 1: Using Python (Recommended)
```bash
# Terminal 1 - Backend
cd backend
mvn spring-boot:run

# Terminal 2 - Frontend
cd frontend
python3 -m http.server 3000

# Browser
http://localhost:3000/login.html
```

### Option 2: Using Node.js
```bash
# Terminal 1 - Backend
cd backend
mvn spring-boot:run

# Terminal 2 - Frontend
cd frontend
npx http-server -p 3000

# Browser
http://localhost:3000/login.html
```

### Option 3: Using VS Code Live Server
```
1. Open frontend folder in VS Code
2. Install "Live Server" extension
3. Right-click login.html
4. Select "Open with Live Server"
5. Start backend separately
```

## 🔌 REST API Endpoints (7 Total)

```
1. POST /api/auth/register
   Register new user account

2. POST /api/auth/login
   User login with credentials

3. POST /api/auth/forgot-password
   Request password reset

4. GET /api/users/{userId}
   Get user profile information

5. PUT /api/users/{userId}
   Update user profile

6. POST /api/users/{userId}/reset-password
   Change user password

7. GET /api/auth/health
   Check API health status

All documented in API_DOCUMENTATION.md with examples
```
